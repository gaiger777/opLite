# 문서

사용 안내는 [docs/guide](guide/)에, 설계와 계획은 아래에 있다.

## 진행 내역

처음 분해한 하위 프로젝트 1~10 완료 (노드 코어 M7, 웹 UI, VM 스냅샷·복제·예약 스냅샷, NFS 공유 스토리지, LVM-thin·ZFS·Ceph RBD·공유 LVM(iSCSI) 풀, 라이브 마이그레이션, 위트니스 노드, Debian 패키지·설치 ISO, 버전과 업데이트, 구독과 텔레메트리, 백업·백업 작업, VMware 가져오기, 감사 로그, LDAP·OIDC, 원격 클러스터·원격 복제), 하위 프로젝트 11 노드 유지보수 모드(노드 비우기) 완료, 하위 프로젝트 12 증분 백업·증분 복제(계획 40·41) 완료, 하위 프로젝트 13 로컬 디스크 라이브 마이그레이션(계획 42) 완료, 제품 이름 Orbivisor로 바꾸기(계획 43) 완료, 하위 프로젝트 14 실시간 지표 수집(계획 44) 완료, 하위 프로젝트 15 제어부 가용성: 실행기 격리와 systemd watchdog(계획 45) 완료, 헬스 체크·세션 공유·API 이름·내장 VIP·앞단 프록시(계획 46) 완료, 리스 확인 묶기·리스 기반 노드 감시·투표 멤버 상한·규모 시험(계획 47) 완료, 관찰 노드(계획 48) 완료, 클러스터 통신 다중 링크(계획 49) 완료, 배치 규칙과 HA 정책(계획 50) 완료, 빠른 HA와 노드 전원 끄기(계획 51) 완료, HA 상태 검사(계획 52) 완료, 최적 배치(계획 53) 완료, VM 무중단 유형 변경(계획 54) 완료, 로컬 디스크 HA(계획 55) 완료, Ceph 자동 구성(계획 56) 완료, 설치 매체와 cloud-init(계획 57) 완료, 템플릿·링크드 클론·이미지 라이브러리(계획 58) 완료, vTPM·Secure Boot·게스트 에이전트(계획 59) 완료, 지표 기록·대시보드·알림·Prometheus(계획 60) 완료, 웹 화면 구성·UX 개편(계획 61) 완료, 폴더·객체 권한·폴더 할당량·2단계 인증(계획 62) 완료
