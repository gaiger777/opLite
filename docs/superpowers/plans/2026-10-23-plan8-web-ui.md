# opLite 계획 8: 웹 UI 기반과 가상 머신 화면 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 브라우저에서 로그인해 대시보드를 보고, VM을 만들고·고치고·시작하고·멈추고·지우며, VM 콘솔(noVNC)에 들어가고, 작업 진행을 실시간으로 보는 웹 UI를 opld에 넣는다(하위 프로젝트 2의 앞 절반).

**Tech Stack:** Rust 2024(MSRV 1.88), axum 0.8, rust-embed 8.13; Node.js 22, pnpm 10.33.2, TypeScript 5.9.3, React 19.3, Vite 8.3, Tailwind CSS 4.3, shadcn/ui(radix-nova), TanStack Query 5·Table 8, React Router 7, openapi-fetch 0.17·openapi-typescript 7.13, i18next 26, noVNC 1.7, Vitest 5, Testing Library, MSW 2, ESLint 10, Prettier 3, Playwright 1.64

## 설계 결정

- **웹 UI는 API와 같은 출처에서 나간다.** 쿠키로 인증한 요청은 `Origin`이 `Host`와 같아야 하므로(계획 5) opld가 UI도 준다. 개발 서버(Vite)는 `/api`(WebSocket 포함)를 opld로 넘기고 Host를 바꾸지 않는다(`changeOrigin` 없음). Chrome은 `http://localhost`에서도 `Secure` 쿠키를 저장한다.
- **`web-ui` 기능과 rust-embed.** 디버그 빌드(테스트, clippy, E2E)는 `web/dist`가 없어도 컴파일되고 안내 페이지를 주며, 파일을 실행 중에 디스크에서 읽는다(`allow_missing`). 릴리스 빌드는 `web/dist`가 없으면 컴파일 오류다. 그래서 Rust CI 작업은 Node 없이 그대로 돈다. 파일 조회는 함수(`fn(&str) -> Option<EmbeddedFile>`)로 넘겨 테스트가 고정 파일을 쓴다.
- **화면 주소는 `index.html`, 빌드 결과는 아니다.** `/assets/`의 없는 파일은 404다(HTML을 스크립트로 읽지 않게). `/api`로 시작하는 경로는 UI로 대체하지 않고 API 오류 JSON으로 답한다.
- **API 타입은 생성한다.** `opl-api-openapi` 바이너리가 라우터와 같은 정의에서 문서를 내고, `pnpm gen:api`가 `schema.d.ts`를 만든다. CI가 다시 만들어 비교한다. 생성 중 끊긴 스키마 참조(`StopMode`)를 찾아 고쳤고, 모든 참조가 문서 안에 있는지 테스트한다.
- **목록이 곧 캐시다.** 리소스마다 TanStack Query 키 `["list", kind]`에 `{revision, items}`를 두고, 상세 화면도 목록에서 찾는다. 로그인하면 6종을 읽고 가장 작은 `revision`부터 watch를 하나 연다. 이벤트는 리소스의 `revision`이 캐시보다 클 때만 적용해 순서가 꼬이지 않는다. 이어 받을 수 없으면(오류, reset, 끊김) 1초부터 30초까지 늘려 가며 목록부터 다시 읽는다.
- **Task는 알림으로 지켜본다.** 202로 받은 Task를 `trackTask`가 "진행 중" 알림으로 띄우고, watch로 바뀐 Task 목록을 `TaskToasts`가 보고 결과 알림으로 바꾼다. VM을 만들며 새 볼륨이 필요하면 `waitForTask`로 그 Task가 끝나기를 기다린다.
- **권한은 서버와 같은 규칙으로 숨긴다.** `can(role, action, kind)`가 `RoleAuthorizer`를 따른다. 실제 확인은 서버가 한다.
- **입력 오류.** 서버의 400 메시지는 필드를 가리키지 않으므로 폼 위에 보여 주고, 흔한 실수(이름 규칙, 최소 메모리, 부팅 순서, MAC)는 보내기 전에 필드 아래에 보여 준다. VM 수정은 `If-Match`로 보내고 412(`revision_mismatch`)면 "다시 불러오기"를 준다.
- **머신 기본값.** API가 노드 아키텍처를 알려 주지 않으므로 모든 노드가 hvf(Apple Silicon)면 `virt`, 아니면 `q35`다.
- **콘솔.** noVNC 1.7은 하위 프로토콜을 요청하지 않아 지금의 콘솔 WebSocket에 그대로 붙는다. 콘솔을 열 때만 내려받는다(`lazy`). 클립보드 입력은 글자를 키 입력으로 보낸다.
- **라이브러리 선택.** shadcn/ui 컴포넌트는 `pnpm dlx shadcn@4.22.1`로 만든 것을 그대로 싣는다(선택 상자는 테스트와 접근성이 쉬운 `native-select`). 테마는 직접 만든다(`next-themes`는 인라인 스크립트를 넣어 CSP에 막힌다). typescript-eslint가 TypeScript 6.1 미만만 지원해 5.9를 쓰고, API가 안정된 TanStack Table 8·React Router 7·MSW 2를 쓴다. React Compiler를 쓰지 않으므로 그 경고 규칙은 끈다.
- **브라우저 E2E는 Rust 테스트가 시작한다.** 기존 하네스(`Daemon`)로 opld를 띄우고 oplctl로 클러스터·풀·볼륨을 준비한 뒤 `pnpm exec playwright test`를 돌린다(`web-it` = `qemu-it` + `web-ui`). OS 없는 UEFI 게스트의 펌웨어 화면이 noVNC 캔버스에 그려지는지 화소로 확인한다.

```rust
//! 웹 UI 정적 파일. `web-ui` 기능으로 빌드하면 `web/dist`(`pnpm -C web build`의 결과)를 바이너리에
//! 넣고, API와 같은 주소에서 준다. 쿠키로 인증한 요청은 Origin이 서버와 같아야 하므로 UI는 같은
//! 출처에서 나가야 한다.

use axum::Router;
use axum::body::Body;
use axum::http::{HeaderValue, Method, StatusCode, Uri, header};
use axum::response::{IntoResponse, Response};
use opl_api::error::ApiError;
use rust_embed::EmbeddedFile;
#[cfg(feature = "web-ui")]
use rust_embed::RustEmbed;

/// 웹 UI가 붙는 응답의 보안 헤더. 스크립트와 연결은 같은 출처로만, 다른 사이트의 frame 안에는 뜨지 않는다.
/// 일부 UI 컴포넌트가 style 속성을 쓰므로 인라인 스타일은 허용하고, noVNC 커서는 `data:` 이미지다.
const CSP: &str = "default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; \
                   img-src 'self' data:; connect-src 'self'; frame-ancestors 'none'";

/// 파일 이름에 내용 해시가 들어간 Vite 빌드 결과
const ASSETS: &str = "assets/";

#[cfg(feature = "web-ui")]
#[derive(RustEmbed)]
#[folder = "../../web/dist"]
// 디버그 빌드(테스트, clippy)는 UI를 빌드하지 않아도 되고 안내 페이지를 준다. 릴리스 빌드에서
// 빠뜨리면 컴파일 오류다. 디버그 빌드는 파일을 실행 중에 디스크에서 읽는다.
#[cfg_attr(debug_assertions, allow_missing = true)]
struct Dist;

/// 경로로 빌드 결과 파일을 찾는다.
type Files = fn(&str) -> Option<EmbeddedFile>;

/// `/api/` 밖의 모든 경로를 웹 UI로 보낸다. API 라우터와 합친다.
pub fn router() -> Router {
    #[cfg(feature = "web-ui")]
    let files: Files = Dist::get;
    #[cfg(not(feature = "web-ui"))]
    let files: Files = |_| None;
    serve(files)
}

fn serve(files: Files) -> Router {
    Router::new().fallback(move |method: Method, uri: Uri| async move {
        if let Some(r) = reject(&method, &uri) {
            return r;
        }
        let path = uri.path().trim_start_matches('/');
        let path = if path.is_empty() { "index.html" } else { path };
        let mut r = match files(path) {
            Some(file) => file_response(path, file),
            // 없는 빌드 결과를 index.html로 주면 브라우저가 HTML을 스크립트로 읽는다.
            None if path.starts_with(ASSETS) => StatusCode::NOT_FOUND.into_response(),
            // 화면 주소(`/vms/web-01`)는 index.html이 받아 브라우저에서 고른다.
            None => match files("index.html") {
                Some(file) => file_response("index.html", file),
                None => return not_built(),
            },
        };
        secure(&mut r);
        r
    })
}

/// 웹 UI 없이 빌드한 opld의 안내
fn not_built() -> Response {
    let page = "<!doctype html><meta charset=\"utf-8\"><title>opLite</title>\
                <p>This opld was built without the web UI. Build it with \
                <code>pnpm -C web build</code> and the <code>web-ui</code> feature. \
                The API is at <code>/api/v1</code>.</p>";
    let mut r = (StatusCode::NOT_FOUND, axum::response::Html(page)).into_response();
    secure(&mut r);
    r
}

/// API 경로는 웹 UI로 대체하지 않고 API 오류(JSON)로 답한다. 정적 파일은 읽기만 한다.
fn reject(method: &Method, uri: &Uri) -> Option<Response> {
    let path = uri.path();
    if path == "/api" || path.starts_with("/api/") {
        return Some(ApiError::not_found(format!("no API at {path}")).into_response());
    }
    if method != Method::GET && method != Method::HEAD {
        return Some(StatusCode::METHOD_NOT_ALLOWED.into_response());
    }
    None
}

fn file_response(path: &str, file: EmbeddedFile) -> Response {
    let cache = if path.starts_with(ASSETS) {
        "public, max-age=31536000, immutable"
    } else {
        "no-cache"
    };
    let mime = file.metadata.mimetype().to_string();
    let mut r = Response::new(Body::from(file.data.into_owned()));
    let h = r.headers_mut();
    h.insert(
        header::CONTENT_TYPE,
        HeaderValue::from_str(&mime)
            .unwrap_or(HeaderValue::from_static("application/octet-stream")),
    );
    h.insert(header::CACHE_CONTROL, HeaderValue::from_static(cache));
    r
}

fn secure(r: &mut Response) {
    let h = r.headers_mut();
    h.insert(
        header::CONTENT_SECURITY_POLICY,
        HeaderValue::from_static(CSP),
    );
    h.insert(
        header::X_CONTENT_TYPE_OPTIONS,
        HeaderValue::from_static("nosniff"),
    );
    h.insert(
        header::REFERRER_POLICY,
        HeaderValue::from_static("no-referrer"),
    );
}
```

```ts
import createClient, { type Middleware } from "openapi-fetch";

import type { components, paths } from "@/api/schema";

/** API가 돌려준 오류(`ErrorBody`). 네트워크 오류는 그대로 `TypeError`다. */
export class ApiError extends Error {
  constructor(
    readonly status: number,
    readonly code: string,
    message: string,
    readonly details?: unknown,
  ) {
    super(message);
    this.name = "ApiError";
  }
}

let onUnauthorized = () => {};

/** 로그인 밖의 요청이 401을 받으면(세션 만료, opld 재시작, 비밀번호 변경) 부른다. */
export function setUnauthorizedHandler(handler: () => void) {
  onUnauthorized = handler;
}

const unauthorized: Middleware = {
  onResponse({ request, response }) {
    if (response.status === 401 && !new URL(request.url).pathname.endsWith("/auth/login")) {
      onUnauthorized();
    }
  },
};

/** 같은 출처의 `/api/v1`. 세션 쿠키는 브라우저가 붙인다. */
export const api = createClient<paths>({
  baseUrl: `${window.location.origin}/api/v1`,
  // 부를 때마다 전역 fetch를 찾는다(테스트의 MSW가 나중에 바꾼다).
  fetch: (request) => globalThis.fetch(request),
});
api.use(unauthorized);

type ErrorBody = components["schemas"]["ErrorBody"];

function isErrorBody(body: unknown): body is ErrorBody {
  return typeof body === "object" && body !== null && "code" in body && "message" in body;
}

export function toApiError(status: number, body: unknown): ApiError {
  if (isErrorBody(body)) {
    return new ApiError(status, body.code, body.message, body.details);
  }
  return new ApiError(status, "internal", `HTTP ${status}`);
}

/** openapi-fetch의 결과에서 데이터를 꺼낸다. 오류 응답이면 `ApiError`를 던진다. */
export async function call<T>(
  request: Promise<{ data?: T; error?: unknown; response: Response }>,
): Promise<T> {
  const { data, error, response } = await request;
  if (!response.ok) {
    throw toApiError(response.status, error);
  }
  return data as T;
}
```

```ts
import type { TFunction } from "i18next";

import { ApiError } from "@/api/client";

/** 오류를 사용자에게 보일 문장으로 바꾼다. API 오류는 `errors.<code>` 번역을 쓰고, 번역이 없으면 서버의 설명을 그대로 쓴다. */
export function errorMessage(t: TFunction, error: unknown): string {
  if (error instanceof ApiError) {
    const key = `errors.${error.code}`;
    return t(key, { message: error.message, defaultValue: error.message });
  }
  if (error instanceof TypeError) {
    return t("errors.network");
  }
  return error instanceof Error ? error.message : String(error);
}
```

```tsx
import { useQueryClient } from "@tanstack/react-query";
import { createContext, useCallback, useContext, useEffect, useMemo, useState } from "react";

import { api, call, setUnauthorizedHandler } from "@/api/client";
import type { Principal } from "@/api/types";

interface Auth {
  /** 확인 중이면 undefined, 로그인하지 않았으면 null */
  principal: Principal | null | undefined;
  login(username: string, password: string): Promise<void>;
  logout(): Promise<void>;
}

const AuthContext = createContext<Auth | null>(null);

export function AuthProvider({ children }: { children: React.ReactNode }) {
  const queryClient = useQueryClient();
  const [principal, setPrincipal] = useState<Principal | null | undefined>(undefined);

  useEffect(() => {
    // 세션이 끝나면(만료, opld 재시작, 비밀번호 변경) 남은 데이터를 지우고 로그인 화면으로 간다.
    setUnauthorizedHandler(() => {
      queryClient.clear();
      setPrincipal(null);
    });
    let live = true;
    call(api.GET("/auth/whoami")).then(
      (p) => live && setPrincipal(p),
      () => live && setPrincipal(null),
    );
    return () => {
      live = false;
    };
  }, [queryClient]);

  const login = useCallback(async (username: string, password: string) => {
    await call(api.POST("/auth/login", { body: { username, password } }));
    setPrincipal(await call(api.GET("/auth/whoami")));
  }, []);

  const logout = useCallback(async () => {
    await call(api.POST("/auth/logout")).catch(() => {});
    queryClient.clear();
    setPrincipal(null);
  }, [queryClient]);

  const value = useMemo(() => ({ principal, login, logout }), [principal, login, logout]);
  return <AuthContext value={value}>{children}</AuthContext>;
}

export function useAuth(): Auth {
  const auth = useContext(AuthContext);
  if (!auth) {
    throw new Error("useAuth outside AuthProvider");
  }
  return auth;
}

/** 로그인한 사용자. 로그인이 필요한 화면 안에서만 쓴다. */
export function usePrincipal(): Principal {
  const { principal } = useAuth();
  if (!principal) {
    throw new Error("usePrincipal outside RequireAuth");
  }
  return principal;
}
```

```tsx
/** 로그인하지 않았으면 로그인 화면으로 보내고, 로그인한 뒤 돌아올 주소를 넘긴다. */
export function RequireAuth() {
  const { principal } = useAuth();
  const location = useLocation();
  if (principal === undefined) {
    return null;
  }
  if (principal === null) {
    const next = location.pathname + location.search;

export function safeNext(next: string | null): string {
```

```ts
/** 읽기, 쓰기(만들기·고치기·지우기), 동작(시작·정지와 콘솔) */

    case "operator":
```

```tsx
import { createContext, useContext, useEffect, useState } from "react";

import { readPref, writePref } from "@/lib/prefs";

export type Theme = "system" | "light" | "dark";

const DARK = "(prefers-color-scheme: dark)";

export function readTheme(): Theme {
  const saved = readPref("theme");
  return saved === "light" || saved === "dark" ? saved : "system";
}

/** `<html>`의 `dark` 클래스로 테마를 바꾼다. 첫 화면이 깜빡이지 않게 그리기 전에도 부른다. */
export function applyTheme(theme: Theme) {
  const dark = theme === "dark" || (theme === "system" && window.matchMedia(DARK).matches);
  document.documentElement.classList.toggle("dark", dark);
}

const ThemeContext = createContext<{ theme: Theme; setTheme(theme: Theme): void } | null>(null);

export function ThemeProvider({ children }: { children: React.ReactNode }) {
  const [theme, setThemeState] = useState<Theme>(readTheme);

  useEffect(() => {
    applyTheme(theme);
    if (theme !== "system") {
      return;
    }
    // 시스템 설정을 따르면 운영체제에서 바꿀 때 함께 바뀐다.
    const media = window.matchMedia(DARK);
    const follow = () => applyTheme("system");
    media.addEventListener("change", follow);
    return () => media.removeEventListener("change", follow);
  }, [theme]);

  const setTheme = (next: Theme) => {
    writePref("theme", next);
    setThemeState(next);
  };
  return <ThemeContext value={{ theme, setTheme }}>{children}</ThemeContext>;
}

export function useTheme() {
  const value = useContext(ThemeContext);
  if (!value) {
    throw new Error("useTheme outside ThemeProvider");
  }
  return value;
}
```

```tsx
import { useQueryClient } from "@tanstack/react-query";
import { createContext, useContext, useEffect, useState } from "react";

import { applyEvent, fetchList, KINDS, type List, listKey, type WatchEvent } from "@/api/live";

export type LiveStatus = "connecting" | "live" | "offline";

const LiveContext = createContext<LiveStatus>("connecting");

const FIRST_RETRY_MS = 1000;
const MAX_RETRY_MS = 30_000;

function watchUrl(since: number) {
  const scheme = window.location.protocol === "https:" ? "wss" : "ws";
  return `${scheme}://${window.location.host}/api/v1/watch?kinds=${KINDS.join(",")}&since=${since}`;
}

/**
 * 로그인한 동안 목록을 모두 읽고, 그중 가장 작은 revision부터 watch를 하나 열어 변경을 캐시에 반영한다.
 * 이어 받을 수 없으면(오류, reset, 연결 끊김) 목록을 다시 읽고 새로 연다.
 */
export function LiveProvider({ children }: { children: React.ReactNode }) {
  const queryClient = useQueryClient();
  const [status, setStatus] = useState<LiveStatus>("connecting");

  useEffect(() => {
    let socket: WebSocket | null = null;
    let timer: ReturnType<typeof setTimeout> | undefined;
    let delay = FIRST_RETRY_MS;
    let stopped = false;

    const retry = () => {
      if (stopped) {
        return;
      }
      setStatus("offline");
      timer = setTimeout(connect, delay);
      delay = Math.min(delay * 2, MAX_RETRY_MS);
    };

    async function connect() {
      let since: number;
      try {
        const lists = await Promise.all(
          KINDS.map((kind) =>
            queryClient.fetchQuery({ queryKey: listKey(kind), queryFn: () => fetchList(kind) }),
          ),
        );
        since = Math.min(...lists.map((list) => list.revision));
      } catch {
        retry();
        return;
      }
      if (stopped) {
        return;
      }
      const ws = new WebSocket(watchUrl(since));
      socket = ws;
      ws.onopen = () => {
        delay = FIRST_RETRY_MS;
        setStatus("live");
      };
      ws.onmessage = (message) => {
        const event = JSON.parse(String(message.data)) as WatchEvent;
        if (event.type === "put" || event.type === "deleted") {
          queryClient.setQueryData<List<{ id: string; revision: number }>>(
            listKey(event.kind),
            (list) => list && applyEvent(list, event),
          );
        } else {
          // reset이나 오류면 이어 받을 수 없다. 닫히면 다시 읽는다.
          ws.close();
        }
      };
      ws.onclose = () => {
        if (socket === ws) {
          socket = null;
          retry();
        }
      };
    }

    void connect();
    return () => {
      stopped = true;
      clearTimeout(timer);
      socket?.close();
      socket = null;
    };
  }, [queryClient]);

  return <LiveContext value={status}>{children}</LiveContext>;
}

/** 실시간 연결 상태 */
export function useLiveStatus(): LiveStatus {
  return useContext(LiveContext);
}
```

```ts
import { useQuery } from "@tanstack/react-query";

import { api, call } from "@/api/client";
import type { Resources, WatchKind } from "@/api/types";

/** 화면이 실시간으로 보는 리소스 종류. 사용자와 토큰은 감시할 수 없다. */
export const KINDS: WatchKind[] = ["vm", "volume", "storage-pool", "node", "task", "network"];

/** 목록 응답. `revision`은 목록을 읽은 시점의 클러스터 revision이다. */
export interface List<T> {
  revision: number;
  items: T[];
}

interface Versioned {
  id: string;
  revision: number;
}

export type WatchEvent =
  | { type: "put"; kind: WatchKind; resource: Versioned }
  | { type: "deleted"; revision: number; kind: WatchKind; resource: Versioned }
  | { type: "reset"; revision: number }
  | { type: "error"; code: string; message?: string };

export function listKey(kind: WatchKind) {
  return ["list", kind] as const;
}

export async function fetchList<K extends WatchKind>(kind: K): Promise<List<Resources[K]>> {
  const list = await (() => {
    switch (kind) {
      case "vm":
        return call(api.GET("/vms"));
      case "volume":
        return call(api.GET("/volumes"));
      case "storage-pool":
        return call(api.GET("/storage-pools"));
      case "node":
        return call(api.GET("/nodes"));
      case "task":
        return call(api.GET("/tasks"));
      case "network":
        return call(api.GET("/networks"));
    }
  })();
  return list as List<Resources[K]>;
}

/**
 * 목록에 이벤트 하나를 반영한다. 리소스의 revision이 목록에 있는 것보다 클 때만 적용하므로, 목록을 읽은
 * 시점보다 오래된 이벤트가 다시 와도 결과가 같다.
 */
export function applyEvent<T extends Versioned>(list: List<T>, event: WatchEvent): List<T> {
  if (event.type !== "put" && event.type !== "deleted") {
    return list;
  }
  const at = list.items.findIndex((item) => item.id === event.resource.id);
  const current = at >= 0 ? list.items[at] : undefined;
  if (event.type === "put") {
    if (current && current.revision >= event.resource.revision) {
      return list;
    }
    const items = [...list.items];
    if (at >= 0) {
      items[at] = event.resource as T;
    } else {
      items.push(event.resource as T);
    }
    return { ...list, items };
  }
  if (!current || current.revision >= event.revision) {
    return list;
  }
  return { ...list, items: list.items.filter((item) => item.id !== event.resource.id) };
}

/** 리소스 목록. 처음에는 직접 읽고, 그 뒤로는 watch가 바꾼다(`LiveProvider`). */
export function useList<K extends WatchKind>(kind: K) {
  return useQuery({
    queryKey: listKey(kind),
    queryFn: () => fetchList(kind),
    staleTime: Infinity,
    select: (list) => list.items,
  });
}
```

```ts
/** UUIDv7 id에 담긴 생성 시각. 리소스 id는 만들 때의 시각을 담는다. */
export function uuidTime(id: string): Date {
  return new Date(parseInt(id.replace(/-/g, "").slice(0, 12), 16));
}

export function formatTime(date: Date, language: string): string {
  return date.toLocaleString(language, { dateStyle: "short", timeStyle: "medium" });
}

/** MiB를 읽기 좋게: 512 MiB, 4 GiB */
export function formatMib(mib: number): string {
  return mib >= 1024 && mib % 1024 === 0 ? `${mib / 1024} GiB` : `${mib} MiB`;
}
```

```tsx
import { useTranslation } from "react-i18next";

import { type List, listKey, useList } from "@/api/live";
import type { Task } from "@/api/types";
import { onTrack, settleTasks } from "@/tasks/tasks";

/** watch로 바뀐 Task 목록을 보고 진행 중 알림을 결과로 바꾼다. */
export function TaskToasts() {
  const { t } = useTranslation();
  const queryClient = useQueryClient();
  const tasks = useList("task");
  useEffect(() => {
    if (tasks.data) {
      settleTasks(tasks.data, t);
    }
  }, [tasks.data, t]);
  // 202 응답보다 watch가 알린 결과가 먼저 올 수 있으므로 지켜보기 시작할 때도 지금 목록을 본다.
  useEffect(
    () =>
      onTrack(() => {
        const list = queryClient.getQueryData<List<Task>>(listKey("task"));
        if (list) {
          settleTasks(list.items, t);
        }
      }),
    [queryClient, t],
  );
  return null;
}
```

```tsx
const SHOWN = 200;

const STATE_VARIANT = {
  pending: "outline",
  running: "secondary",
  succeeded: "default",
  failed: "destructive",
} as const;

export function TaskStateBadge({ task }: { task: Task }) {
  const { t } = useTranslation();
  return (
    <Badge variant={STATE_VARIANT[task.status.state]}>
      {t(`tasks.state.${task.status.state}`)}
    </Badge>
  );
}

/** Task 대상의 이름. VM이면 VM 화면으로 이어진다. */
export function useTaskTarget() {
  const vms = useList("vm");
  const volumes = useList("volume");
  return (task: Task) => {
    const vm = vms.data?.find((v) => v.id === task.spec.target);
    if (vm) {
      return { name: vm.name, href: `/vms/${encodeURIComponent(vm.name)}` };
    }
    const volume = volumes.data?.find((v) => v.id === task.spec.target);
    return { name: volume?.name ?? task.spec.target.slice(0, 8), href: undefined };
  };
}

/** Task 표. VM 화면의 작업 탭도 쓴다. */
export function TaskTable({ tasks }: { tasks: Task[] }) {
  const { t, i18n } = useTranslation();
  const target = useTaskTarget();
  const nodes = useList("node");
  return (
    <Table>
      <TableHeader>
        <TableRow>
          <TableHead>{t("tasks.time")}</TableHead>
          <TableHead>{t("tasks.operation")}</TableHead>
          <TableHead>{t("tasks.node")}</TableHead>
          <TableHead>{t("tasks.stateColumn")}</TableHead>
          <TableHead>{t("tasks.error")}</TableHead>
        </TableRow>
      </TableHeader>
      <TableBody>
        {tasks.length === 0 && (
          <TableRow>
            <TableCell colSpan={5} className="text-center text-muted-foreground">
              {t("tasks.empty")}
            </TableCell>
          </TableRow>
        )}
        {tasks.map((task) => {
          const { name, href } = target(task);
          const node = nodes.data?.find((n) => n.id === task.spec.node);
          return (
            <TableRow key={task.id}>
              <TableCell className="whitespace-nowrap">
                {formatTime(uuidTime(task.id), i18n.language)}
              </TableCell>
              <TableCell>
                {href ? (
                  <Link to={href} className="underline-offset-4 hover:underline">
                    {describeTask(task, t, name)}
                  </Link>
                ) : (
                  describeTask(task, t, name)
                )}
              </TableCell>
              <TableCell>{node?.name ?? "—"}</TableCell>
              <TableCell>
                <TaskStateBadge task={task} />
              </TableCell>
              <TableCell className="max-w-md truncate" title={task.status.error ?? undefined}>
                {task.status.error ?? ""}
              </TableCell>
            </TableRow>
          );
        })}
      </TableBody>
    </Table>
  );
}

/** 최근 순으로 정렬한다(id가 UUIDv7이라 문자열 순서가 시간 순서다). */
export function newestFirst(tasks: Task[]): Task[] {
  return [...tasks].sort((a, b) => (a.id < b.id ? 1 : -1));
}

export function TasksPage() {
  const { t } = useTranslation();
  const tasks = useList("task");
  const [failedOnly, setFailedOnly] = useState(false);
  const shown = useMemo(
    () =>
      newestFirst(tasks.data ?? [])
        .filter((task) => !failedOnly || task.status.state === "failed")
        .slice(0, SHOWN),
    [tasks.data, failedOnly],
  );
  return (
    <div className="flex flex-col gap-4">
      <div className="flex items-center justify-between gap-4">
        <h1 className="text-2xl font-semibold">{t("nav.tasks")}</h1>
        <div className="flex items-center gap-2">
          <Checkbox
            id="failed-only"
            checked={failedOnly}
            onCheckedChange={(v) => setFailedOnly(v === true)}
          />
          <Label htmlFor="failed-only">{t("tasks.failedOnly")}</Label>
        </div>
      </div>
      <TaskTable tasks={shown} />
    </div>
  );
}
```

```ts
import type { TFunction } from "i18next";
import { toast } from "sonner";

import type { Task } from "@/api/types";

/** 결과를 기다리는 Task: id → 알림에 쓸 설명 */
const pending = new Map<string, string>();

let tracked = () => {};

/** 지켜볼 Task가 생기면 부를 함수를 정한다(`TaskToasts`). 해제 함수를 돌려준다. */
export function onTrack(listener: () => void) {
  tracked = listener;
  return () => {
    tracked = () => {};
  };
}

/**
 * API가 202로 돌려준 Task의 진행을 알림으로 보여 준다. 결과는 watch로 들어온 Task 목록에서
 * `settleTasks`가 찾는다.
 */
export function trackTask(task: Task, label: string) {
  pending.set(task.id, label);
  toast.loading(label, { id: task.id });
  tracked();
}

/** 끝난 Task의 알림을 결과로 바꾼다. Task 목록이 바뀔 때마다 부른다. */
export function settleTasks(tasks: Task[], t: TFunction) {
  for (const task of tasks) {
    const label = pending.get(task.id);
    if (label === undefined) {
      continue;
    }
    if (task.status.state === "succeeded") {
      pending.delete(task.id);
      toast.success(t("tasks.done", { label }), { id: task.id });
    } else if (task.status.state === "failed") {
      pending.delete(task.id);
      toast.error(t("tasks.failed", { label, error: task.status.error ?? "" }), {
        id: task.id,
        duration: Infinity,
        closeButton: true,
      });
    }
  }
}

/** Task를 사람이 읽을 문장으로: "web-01 시작" */
export function describeTask(task: Task, t: TFunction, target: string): string {
  return t(`tasks.op.${task.spec.op.kind}`, { target });
}
```

```tsx
import { useState } from "react";
import { useTranslation } from "react-i18next";

import {
  AlertDialog,
  AlertDialogCancel,
  AlertDialogContent,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogHeader,
  AlertDialogTitle,
} from "@/components/ui/alert-dialog";
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";
import { Label } from "@/components/ui/label";
import { errorMessage } from "@/i18n/errors";

interface Props {
  open: boolean;
  onOpenChange(open: boolean): void;
  title: string;
  description: string;
  confirmLabel: string;
  /** 주면 이 이름을 그대로 입력해야 진행한다(되돌릴 수 없는 삭제). */
  typeToConfirm?: string;
  /** 실패하면 던진다. 대화상자가 오류를 보여 준다. */
  onConfirm(): Promise<void>;
}

/** 되돌릴 수 없는 동작을 확인한다. */
export function ConfirmDialog(props: Props) {
  const { t } = useTranslation();
  const [typed, setTyped] = useState("");
  const [error, setError] = useState<string | null>(null);
  const [busy, setBusy] = useState(false);
  const ready = props.typeToConfirm === undefined || typed === props.typeToConfirm;

  function openChange(open: boolean) {
    if (!open) {
      setTyped("");
      setError(null);
    }
    props.onOpenChange(open);
  }

  async function confirm() {
    setBusy(true);
    setError(null);
    try {
      await props.onConfirm();
      openChange(false);
    } catch (err) {
      setError(errorMessage(t, err));
    } finally {
      setBusy(false);
    }
  }

  return (
    <AlertDialog open={props.open} onOpenChange={openChange}>
      <AlertDialogContent>
        <AlertDialogHeader>
          <AlertDialogTitle>{props.title}</AlertDialogTitle>
          <AlertDialogDescription>{props.description}</AlertDialogDescription>
        </AlertDialogHeader>
        {props.typeToConfirm !== undefined && (
          <div className="flex flex-col gap-2">
            <Label htmlFor="confirm-name">
              {t("confirm.typeName", { name: props.typeToConfirm })}
            </Label>
            <Input
              id="confirm-name"
              autoComplete="off"
              value={typed}
              onChange={(e) => setTyped(e.target.value)}
            />
          </div>
        )}
        {error && (
          <p role="alert" className="text-sm text-destructive">
            {error}
          </p>
        )}
        <AlertDialogFooter>
          <AlertDialogCancel>{t("confirm.cancel")}</AlertDialogCancel>
          <Button variant="destructive" disabled={!ready || busy} onClick={() => void confirm()}>
            {props.confirmLabel}
          </Button>
        </AlertDialogFooter>
      </AlertDialogContent>
    </AlertDialog>
  );
}
```

```tsx
export function VmMenu({ vm }: { vm: Vm }) {
  const { t } = useTranslation();
  const me = usePrincipal();
  const navigate = useNavigate();
  const { run, remove } = useVmActions();
  const [confirm, setConfirm] = useState<"force-stop" | "delete" | null>(null);

  const write = can(me.role, "write", "vm");
  if (!operate && !write) {
    return null;
  }
  return (
    <>
      {/* 메뉴에서 대화상자를 열므로 모달로 두지 않는다(닫힌 메뉴가 화면 클릭을 막지 않게). */}
      <DropdownMenu modal={false}>
        <DropdownMenuTrigger asChild>
          <Button
            variant="ghost"
            size="icon-sm"
            aria-label={t("vms.actionsFor", { name: vm.name })}
          >
            <MoreHorizontal />
          </Button>
        </DropdownMenuTrigger>
        <DropdownMenuContent align="end">
          {operate &&
            ACTIONS.map((action) => (
              <DropdownMenuItem
                key={action}
                disabled={!canRun(vm, action)}
                onSelect={() =>
                  action === "force-stop" ? setConfirm("force-stop") : void run(vm, action)
                }
              >
                {t(`vms.action.${action}`)}
              </DropdownMenuItem>
            ))}
          {operate && (
            <DropdownMenuItem
              disabled={vm.status.phase !== "running"}
              onSelect={() => void navigate(`/vms/${encodeURIComponent(vm.name)}/console`)}
            >
              {t("vms.action.console")}
            </DropdownMenuItem>
          )}
          {write && (
            <>
              <DropdownMenuSeparator />
              <DropdownMenuItem
                variant="destructive"
                disabled={!canDelete(vm)}
                onSelect={() => setConfirm("delete")}
              >
                {t("vms.action.delete")}
              </DropdownMenuItem>
            </>
          )}
        </DropdownMenuContent>
      </DropdownMenu>
      <VmConfirm
        vm={vm}
        which={confirm}
        onClose={() => setConfirm(null)}
        onRun={run}
        onRemove={remove}
      />
    </>
  );
}

/** 강제 정지와 삭제의 확인 대화상자 */
export function VmConfirm({
  vm,
  which,
  onClose,
  onRun,
  onRemove,
  afterRemove,
}: {
  vm: Vm;
  which: "force-stop" | "delete" | null;
  onClose(): void;
  onRun(vm: Vm, action: VmAction): Promise<void>;
  onRemove(vm: Vm): Promise<void>;
  afterRemove?(): void;
}) {
  const { t } = useTranslation();
  return (
    <>
      <ConfirmDialog
        open={which === "force-stop"}
        onOpenChange={(open) => !open && onClose()}
        title={t("vms.forceStopTitle", { name: vm.name })}
        description={t("vms.forceStopDescription")}
        confirmLabel={t("vms.action.force-stop")}

        description={t("vms.deleteDescription")}

        typeToConfirm={vm.name}
        onConfirm={async () => {
          await onRemove(vm);
          afterRemove?.();
        }}
      />
    </>
  );
}
```

```ts
import { useTranslation } from "react-i18next";
import { toast } from "sonner";

import { api, call } from "@/api/client";
import type { Vm } from "@/api/types";
import { errorMessage } from "@/i18n/errors";
import { trackTask } from "@/tasks/tasks";

export type VmAction = "start" | "stop" | "force-stop" | "reboot";

/** 지금 상태에서 할 수 있는 동작인지. 서버도 확인하지만 할 수 없는 버튼은 막아 둔다. */
export function canRun(vm: Vm, action: VmAction): boolean {
  const phase = vm.status.phase;
  switch (action) {
    case "start":
      return phase === "stopped" || phase === "failed";
    case "stop":
      return phase === "running" || phase === "starting";
    case "force-stop":
      return phase === "running" || phase === "starting" || phase === "stopping";
    case "reboot":
      return phase === "running";
  }
}

/** 지울 수 있는 상태인지(서버는 실행 중인 VM을 지우지 않는다) */
export function canDelete(vm: Vm): boolean {
  return vm.status.phase === "stopped" || vm.status.phase === "failed";
}

export function useVmActions() {
  const { t } = useTranslation();

  /** 동작을 요청하고 그 Task를 알림으로 지켜본다. 실패는 알림으로 보여 준다. */
  async function run(vm: Vm, action: VmAction) {
    try {
      const task = await call(
        api.POST("/vms/{key}/actions/{action}", {
          params: {
            path: { key: vm.id, action: action === "force-stop" ? "stop" : action },
            query: action === "force-stop" ? { mode: "force" } : {},
          },
        }),
      );
      trackTask(task, t(`tasks.op.vm-${action}`, { target: vm.name }));
    } catch (err) {
      toast.error(errorMessage(t, err));
    }
  }

  /** VM을 지운다. 실패하면 던진다(확인 대화상자가 보여 준다). 볼륨은 남는다. */
  async function remove(vm: Vm) {
    await call(api.DELETE("/vms/{key}", { params: { path: { key: vm.id } } }));
    toast.success(t("vms.deleted", { name: vm.name }));
  }

  return { run, remove };
}
```

```ts
/** watch로 들어온 Task 목록에서 그 Task가 끝나기를 기다린다. 실패하면 Task의 오류로 거부한다. */
export function waitForTask(queryClient: QueryClient, id: string): Promise<Task> {
  const key = hashKey(listKey("task"));
  return new Promise((resolve, reject) => {
    let unsubscribe = () => {};
    const check = () => {
      const task = queryClient
        .getQueryData<List<Task>>(listKey("task"))
        ?.items.find((t) => t.id === id);
      if (task?.status.state === "succeeded") {
        unsubscribe();
        resolve(task);
      } else if (task?.status.state === "failed") {
        unsubscribe();
        reject(new Error(task.status.error ?? "task failed"));
      }
    };
    unsubscribe = queryClient.getQueryCache().subscribe((event) => {
      if (event.query.queryHash === key) {
        check();
      }
    });
    check();
  });
}
```

```tsx
function VmForm({ vm, initial }: { vm?: Vm; initial: VmFormValues }) {

  const volumes = useList("volume");
  const [values, setValues] = useState(initial);
  const [revision, setRevision] = useState(vm?.revision);
  const [errors, setErrors] = useState<Record<string, string>>({});
  const [failure, setFailure] = useState<{ message: string; conflict: boolean } | null>(null);
  const [busy, setBusy] = useState(false);
  const creating = vm === undefined;
  // 실행 중인 VM의 노드와 디스크는 서버가 바꾸지 않는다.
  const locked = !creating && vm.status.phase !== "stopped" && vm.status.phase !== "failed";

  const set = <K extends keyof VmFormValues>(key: K, value: VmFormValues[K]) =>
    setValues((v) => ({ ...v, [key]: value }));
  const setDisk = (i: number, patch: Partial<DiskRow>) =>
    set(
      "disks",
      values.disks.map((d, j) => (j === i ? { ...d, ...patch } : d)),

      .getQueryData<{ items: Vm[] }>(["list", "vm"])
      ?.items.find((v) => v.id === vm?.id);
```

```ts
import type { components } from "@/api/schema";
import type { Node, Vm, VmSpec } from "@/api/types";

type Schemas = components["schemas"];

/** 서버의 `MIN_MEMORY_MIB` */
export const MIN_MEMORY_MIB = 64;
/** 서버의 리소스 이름 규칙: 소문자·숫자·`-`, 63자까지, `-`로 시작하거나 끝나지 않는다. */
const NAME = /^[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?$/;
const UUID = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;
const MAC = /^[0-9a-f]{2}(:[0-9a-f]{2}){5}$/i;

export interface DiskRow {
  /** 있는 볼륨을 붙이거나, 만들기 전에 새 빈 볼륨을 만든다. */
  kind: "existing" | "new";
  volume: string;
  pool: string;
  sizeGib: string;
  bus: Schemas["DiskBus"];
  bootOrder: string;
}

export interface NicRow {
  network: string;
  model: Schemas["NicModel"];
  mac: string;
}

export interface VmFormValues {
  name: string;
  sockets: number;
  cores: string;
  model: Schemas["CpuModel"];
  memory: string;
  firmware: Schemas["Firmware"];
  machine: Schemas["MachineType"];
  disks: DiskRow[];
  nics: NicRow[];
  /** 빈 문자열이면 스케줄러가 고른다. */
  node: string;
  restart: Schemas["RestartPolicy"];
  /** 만든 뒤 곧바로 시작한다(만들 때만). */
  start: boolean;
}

/**
 * 노드의 아키텍처를 API가 알려 주지 않으므로, 모든 노드가 hvf(Apple Silicon)면 `virt`, 아니면 `q35`를
 * 기본값으로 한다. 다른 경우는 사용자가 고른다.
 */
export function defaultMachine(nodes: Node[]): Schemas["MachineType"] {
  return nodes.length > 0 && nodes.every((n) => n.status.hypervisor === "qemu-hvf")
    ? "virt"
    : "q35";
}

export function emptyDisk(vmName: string, index: number): DiskRow {
  return {
    kind: "new",
    volume: vmName ? `${vmName}-disk${index}` : "",
    pool: "",
    sizeGib: "16",
    bus: "virtio-blk",
    bootOrder: index === 0 ? "1" : "",
  };
}

export function emptyForm(machine: Schemas["MachineType"]): VmFormValues {
  return {
    name: "",
    sockets: 1,
    cores: "2",
    model: "host",
    memory: "2048",
    firmware: "uefi",
    machine,
    disks: [],
    nics: [{ network: "user", model: "virtio", mac: "" }],
    node: "",
    restart: "never",
    start: true,
  };
}

export function fromVm(vm: Vm): VmFormValues {
  const s = vm.spec;
  return {
    name: vm.name,
    sockets: s.cpu.sockets ?? 1,
    cores: String(s.cpu.cores),
    model: s.cpu.model ?? "host",
    memory: String(s.memory_mib),
    firmware: s.firmware ?? "uefi",
    machine: s.machine,
    disks: (s.disks ?? []).map((d) => ({
      kind: "existing",
      volume: d.volume,
      pool: "",
      sizeGib: "",
      bus: d.bus,
      bootOrder: d.boot_order == null ? "" : String(d.boot_order),
    })),
    nics: (s.nics ?? []).map((n) => ({ network: n.network, model: n.model, mac: n.mac ?? "" })),
    node: s.node ?? "",
    restart: s.restart ?? "never",
    start: false,
  };
}

/** 입력 오류: 필드 → 번역 키. 서버도 검증하지만 흔한 실수는 보내기 전에 알린다. */
export function validate(v: VmFormValues, creating: boolean): Record<string, string> {
  const errors: Record<string, string> = {};
  const nameOk = (name: string) => NAME.test(name) && !UUID.test(name);
  if (creating && !nameOk(v.name)) {
    errors.name = "vmForm.errors.name";
  }
  if (!(Number.isInteger(Number(v.cores)) && Number(v.cores) >= 1)) {
    errors.cores = "vmForm.errors.cores";
  }
  if (!(Number.isInteger(Number(v.memory)) && Number(v.memory) >= MIN_MEMORY_MIB)) {
    errors.memory = "vmForm.errors.memory";
  }
  const boots = new Set<string>();
  v.disks.forEach((d, i) => {
    if (!nameOk(d.volume)) {
      errors[`disks.${i}.volume`] = "vmForm.errors.volume";
    }
    if (d.kind === "new" && !d.pool) {
      errors[`disks.${i}.pool`] = "vmForm.errors.pool";
    }
    if (d.kind === "new" && !(Number(d.sizeGib) > 0)) {
      errors[`disks.${i}.size`] = "vmForm.errors.size";
    }
    if (d.bootOrder !== "") {
      if (
        !(Number.isInteger(Number(d.bootOrder)) && Number(d.bootOrder) >= 1) ||
        boots.has(d.bootOrder)
      ) {
        errors[`disks.${i}.bootOrder`] = "vmForm.errors.bootOrder";
      }
      boots.add(d.bootOrder);
    }
  });
  v.nics.forEach((n, i) => {
    if (n.mac !== "" && !MAC.test(n.mac)) {
      errors[`nics.${i}.mac`] = "vmForm.errors.mac";
    }
  });
  return errors;
}

/** 폼 값을 VM spec으로. `power`는 만들 때만 정하고, 고칠 때는 지금 값을 그대로 둔다. */
export function toSpec(v: VmFormValues, power: Schemas["PowerState"]): VmSpec {
  return {
    cpu: { sockets: v.sockets, cores: Number(v.cores), model: v.model },
    memory_mib: Number(v.memory),
    firmware: v.firmware,
    machine: v.machine,
    disks: v.disks.map((d) => ({
      volume: d.volume,
      bus: d.bus,
      boot_order: d.bootOrder === "" ? null : Number(d.bootOrder),
    })),
    nics: v.nics.map((n) => ({
      network: n.network,
      model: n.model,
      mac: n.mac === "" ? null : n.mac.toLowerCase(),
    })),
    node: v.node === "" ? null : v.node,
    power,
    restart: v.restart,
  };
}
```

```tsx
import RFB from "@novnc/novnc";
import { useEffect, useRef, useState } from "react";
import { useTranslation } from "react-i18next";
import { toast } from "sonner";

import type { Vm } from "@/api/types";
import { Button } from "@/components/ui/button";
import { keysym } from "@/vms/keysyms";

type State = "connecting" | "connected" | "failed";

export function consoleUrl(vm: Vm) {
  const scheme = window.location.protocol === "https:" ? "wss" : "ws";
  return `${scheme}://${window.location.host}/api/v1/vms/${encodeURIComponent(vm.id)}/console`;
}

/**
 * VM 화면(VNC). API가 WebSocket으로 RFB를 그대로 넘기므로 noVNC가 곧바로 붙는다. 세션 쿠키는 같은
 * 출처라 브라우저가 붙인다. 연결이 끊기면 다시 연결 버튼을 보여 준다.
 */
export default function VmConsole({ vm }: { vm: Vm }) {
  const { t } = useTranslation();
  const screen = useRef<HTMLDivElement>(null);
  const rfb = useRef<RFB | null>(null);
  const [state, setState] = useState<State>("connecting");
  const [attempt, setAttempt] = useState(0);
  const running = vm.status.phase === "running";

  useEffect(() => {
    if (!running || !screen.current) {
      return;
    }
    setState("connecting");
    const client = new RFB(screen.current, consoleUrl(vm));
    client.scaleViewport = true;
    client.addEventListener("connect", () => setState("connected"));
    client.addEventListener("disconnect", () => setState("failed"));
    rfb.current = client;
    return () => {
      rfb.current = null;
      client.disconnect();
    };
    // VM id가 같으면 상태가 바뀌어도 다시 연결하지 않는다.
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [vm.id, running, attempt]);

  async function paste() {
    try {
      const text = await navigator.clipboard.readText();
      for (const char of text) {
        rfb.current?.sendKey(keysym(char), null);
      }
    } catch {
      toast.error(t("console.pasteDenied"));
    }
  }

  if (!running) {
    return <p className="text-sm text-muted-foreground">{t("errors.vm_not_running")}</p>;
  }
  return (
    <div className="flex flex-col gap-2">
      <div className="flex flex-wrap items-center gap-2 text-sm">
        <span role="status" className="mr-2 text-muted-foreground">
          {t(`console.${state}`)}
        </span>
        {state === "failed" && (
          <Button size="sm" variant="outline" onClick={() => setAttempt((n) => n + 1)}>
            {t("console.reconnect")}
          </Button>
        )}
        <Button
          size="sm"
          variant="outline"
          disabled={state !== "connected"}
          onClick={() => rfb.current?.sendCtrlAltDel()}
        >
          Ctrl+Alt+Del
        </Button>
        <Button
          size="sm"
          variant="outline"
          disabled={state !== "connected"}
          onClick={() => void paste()}
        >
          {t("console.paste")}
        </Button>
        <Button
          size="sm"
          variant="outline"
          onClick={() => void screen.current?.requestFullscreen()}
        >
          {t("console.fullscreen")}
        </Button>
      </div>
      <div
        ref={screen}
        data-testid="console-screen"
        className="aspect-[4/3] w-full overflow-hidden rounded-md bg-black"
      />
    </div>
  );
}
```

```ts
/** 글자를 X11 keysym으로. Latin-1은 코드 포인트 그대로, 나머지 유니코드는 0x01000000을 더한다. */
export function keysym(char: string): number {
  if (char === "\n") {
    return 0xff0d; // Return
  }
  if (char === "\t") {
    return 0xff09; // Tab
  }
  const code = char.codePointAt(0) ?? 0;
  return code < 0x100 ? code : 0x01000000 + code;
}
```

- **페이지 나누기 없음:** 작업 목록은 모두 받아 최근 200개(대시보드 5개, VM 화면 50개)만 보여 준다.
- **머신 기본값:** 노드 아키텍처를 모르므로 hvf 노드만 있으면 `virt`, 아니면 `q35`. 섞인 클러스터에서는 사용자가 고른다.
- **콘솔 실패 이유:** WebSocket 업그레이드 전의 API 오류(409 `vm_not_running`, 502 `console_unavailable`)는 브라우저가 본문을 주지 않아 "연결이 끊겼다"로만 보인다.
- **클립보드 입력:** 키 입력으로 보내므로 게스트 키보드 배치가 US가 아니면 기호가 바뀔 수 있다.
- **새 볼륨으로 VM 만들기:** 볼륨을 만든 뒤 VM 만들기가 실패하면 볼륨은 남는다(볼륨 화면은 계획 9).
- **개발 의존성 취약점:** shadcn CLI(개발 의존성)가 끌어오는 `braces`에 알려진 취약점이 있다. 배포물에는 들어가지 않아 CI는 `--prod`만 검사한다.
- **`cargo test --all-features`:** 웹 E2E까지 켜므로 pnpm·Chromium·빌드한 `web/dist`가 필요하다.
