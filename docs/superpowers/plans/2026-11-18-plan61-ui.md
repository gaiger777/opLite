# Orbivisor 계획 61: 웹 화면 구성·UX 개편 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 26개 항목을 평평하게 늘어놓던 웹 사이드바를 최상위 영역 6개로 줄이고 하위 화면은 영역 안 탭으로 고르게 하며, ⌘K 명령 팔레트·머리줄 검색·+ 만들기·작업·알림 센터·공통 데이터 표(저장 보기·일괄 동작·미리 보기)·상세 틀·파괴 동작 안전·홈 대시보드·마법사·휴대폰 당직 보기·단축키·디자인 토큰으로 운영 편의를 높인다.

**Architecture:**
- **한 곳의 정의:** `web/src/layout/nav.ts`의 `AREAS`(영역 → 탭 → 보기, 권한 `kind`·`admin`)가 사이드바·영역 탭·보기 전환·이동 경로·팔레트 이동 항목·넘기기 시험의 원천이다. `areaOf(pathname)`이 가장 긴 접두사로 영역과 탭을 찾고, 마지막 탭은 `prefs` `nav.last.{area}`에 둔다.
- **주소는 거의 그대로:** 리소스 주소를 지키고 설정으로 옮긴 셋(`/users`·`/realms`·`/tokens` → `/settings/*`)만 쿼리·해시를 지켜 `replace`로 넘긴다. opld는 바뀌지 않는다(`web.rs` fallback).
- **같은 대화상자:** `VmActionHost`가 VM 대화상자 상태를 맥락으로 올려 행 메뉴·상세 머리·팔레트·서랍·전원 단추가 같은 확인을 연다. 팔레트는 확인이 없는 동작만 바로 한다.
- **새 API 없음:** 팔레트·센터·홈은 `useList` 실시간 캐시와 계획 60의 `useAlerts()`만 읽는다. 즐겨찾기·최근·저장 보기·열·밀도는 브라우저 `prefs`다.
- **디자인 토큰:** `index.css`의 강조·상태·차트·표면·그림자·모서리·밀도·움직임 토큰, 밝음·어두움, `prefers-reduced-motion`, 대비 시험.

**Tech Stack:** React 19·react-router 7·TanStack Query·react-table, Tailwind 4·shadcn(`radix-ui` 1.8.1 묶음: Sheet·Tooltip·Popover·ToggleGroup), lucide, sonner, Vitest·Testing Library·msw, 개발 의존성 `axe-core` 4.10.3, Playwright(opld `web-it`).

**설계 문서:** `docs/superpowers/specs/2026-11-18-ui-ux-redesign-design.md`
**선행 계획:** 계획 1~60 (완료)

## 실행 환경

- **이 Mac에서 하는 것:** 모든 웹 변경과 `pnpm typecheck`·`pnpm lint`·`pnpm test`(Vitest·jsdom·msw·axe), vite preview·Chromium 눈 확인, 묶음 크기 재기(`index.html`이 받는 JS gzip 합), 그리고 스테이지 6부터 **로컬 브라우저 E2E** `pnpm -C web build && cargo test -p opld --features web-it --test web`(Homebrew QEMU·Playwright Chromium).
- **배포 서버 svc01(Linux aarch64):** 일반 시험 묶음(Rust는 바뀌지 않음 — 회귀 확인).
- **GitHub(Ubuntu 24.04 x86_64):** `linux-kvm`의 "Web UI and browser"(같은 `vm.spec.ts`)를 탐침으로 돌린다.
- **테스트 VM:** 두 노드에 배포한 뒤 새 웹 묶음이 나오는지, 옛 주소 넘기기와 주요 화면을 확인한다.

## 설계 결정

- **사이드바 트리 대신 영역 6개 + 영역 안 탭:** 사용자가 바란 "좌측은 최대한 간단히"를 지킨다. 탭 하나 더 누르는 대가는 마지막 탭 기억·팔레트·즐겨찾기·`g` 단축키가 지운다.
- **리소스 주소 유지 + 메타데이터로 묶기:** 북마크·문서·E2E가 그대로이고 넘기기는 셋뿐이다.
- **직접 만든 팔레트(`cmdk` 없음):** 순위·IP·동작 문법을 어차피 직접 짜고, 낱개 radix 패키지가 겹치지 않는다.
- **팔레트는 같은 확인 대화상자:** 손가락 실수가 정지·옮기기가 되지 않는다.
- **클라이언트 다시 하기(파라미터 없는 op만):** Task에 요청 파라미터가 없어 서버 API 없이 할 수 있는 만큼만.
- **즐겨찾기·저장 보기는 브라우저:** 새 리소스 종류·API·권한 없이 바로 쓴다(동기화는 다음으로).
- **같은 앱의 반응형 당직 보기:** 따로 앱 없이 홈·경보·전원만 다듬는다.

## 완료 기준 (계획 61)

- 사이드바 항목이 6개이고 둘째 단계가 없으며, 모든 하위 화면이 영역 탭·보기 전환으로 닿는다. 권한(admin·operator·viewer)별로 보이는 영역·탭이 맞다(`nav.test.ts`).
- 옛 사이드바 26개 주소가 모두 화면을 열고, `/users`·`/realms`·`/tokens`가 쿼리·해시를 지켜 `/settings/*`로, `/infra`·`/protect`·`/activity`가 기억한 탭(없거나 권한 밖이면 첫 탭)으로 간다(`routes.test.tsx`).
- ⌘K·Ctrl+K로 팔레트가 열리고 이름·IP·CIDR·노드 주소로 찾으며, "migrate web to node2"가 옮기기 대화상자를 node2로 채워 열 뿐 실행하지 않고, viewer에게 동작이 없으며, Esc 뒤 포커스가 돌아온다.
- VM 일괄 동작이 가능·불가 수와 이유를 보이고, 지우기·강제 정지는 수를 입력해야 하며, 요청이 4개씩이고 결과 알림이 하나다.
- 종 숫자와 서랍의 세 묶음, 다시 하기가 같은 전원 API를 부르고 파라미터가 필요한 op에는 다시 하기가 없다.
- 되돌릴 수 없는 동작의 확인에 영향 목록과 입력 확인이 있고 기본 포커스가 취소다. 되돌리기 알림이 이전 값을 `If-Match`로 다시 쓴다.
- 홈·첫 걸음·VM 만들기 프리셋과 단계 목록·합류 단계·휴대폰 홈 순서가 시험으로 굳어 있다.
- 색 토큰이 대비 시험(글 4.5:1, 상태 칩 4.5:1, 포커스 링·차트 3:1)을 지나고, 셸·팔레트·서랍·VM 목록·VM 상세·설정·홈에서 axe 위반이 없다. ko/en 키가 같다.
- 첫 화면 JS 증가가 25 KB gzip 이하다.
- `pnpm typecheck`·`lint`·`test`, 로컬 브라우저 E2E, GitHub `linux-kvm` "Web UI and browser"가 통과한다. Rust는 바뀌지 않고 svc01 일반 시험이 통과한다.

## 알고 받아들인 제한

- 즐겨찾기·최근 항목·저장 보기·열 설정·마지막 탭·레일 접기는 그 브라우저의 localStorage에만 있다(사용자마다 따로, 기기 사이 동기화 없음).
- 팔레트의 DHCP 게스트 IP 찾기는 그 브라우저에서 게스트 정보를 받은 VM만 된다(모든 VM의 게스트 IP를 미리 모으지 않음). 네트워크 리소스에 CIDR 칸이 없어 CIDR 질의는 범위 안의 VM 주소를 찾는다.
- 다시 하기는 VM 전원 넷과 백업 작업 다시 실행만이다(Task에 요청 파라미터가 없음). 정지·강제 정지 다시 하기는 확인 없이 보낸다.
- 일괄 동작은 VM 목록에만, 미리 보기 서랍은 VM·노드 목록에만 있다. 일괄 스냅샷은 디스크만 담고 스냅샷이 있는 VM은 일괄 지우기에서 빠진다.
- 열은 숨기기만 하고 순서를 바꾸지 않는다. 작업·감사 목록은 페이지 나누기 때문에 검색·정렬이 없다.
- VM 만들기 단계 폼은 절을 접지 않는다(숨은 오류를 키보드·화면 읽기 사용자가 놓치지 않게). 합류 마법사는 새 화면이 아니라 지금 대화상자에 단계 표시를 단 것이다.
- 노드 펜스·TPM 초기화·백업 지우기 확인에는 영향 목록이 없다(대상 하나를 이미 설명함). 경보 규칙 켜기의 낙관적 갱신은 없다(목록에 바로 바꾸는 스위치가 없음).
- 빈 상태의 문서 링크(`docsHref`)는 앱 안에 문서 주소 규약이 없어 달지 않았다.
- 화면 회귀 스냅숏 시험, RTL, 고대비 테마는 없다.
